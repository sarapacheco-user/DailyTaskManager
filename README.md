# 🗓️ Daily Task Manager (under reforming)

A simple and functional **Daily Task Manager** web application built with **Node.js**, **MongoDB**, **JavaScript**, **HTML**, and **CSS**.

This project allows users to create, manage, and organize daily tasks with an intuitive interface and persistent storage.

---

## 🚀 Technologies Used

- **Backend**
  - Node.js
  - Express.js
  - MongoDB (Mongoose)

- **Frontend**
  - HTML
  - CSS
  - JavaScript

---

## 📦 Features

- Add, edit, and delete daily tasks
- Mark tasks as complete/incomplete
- MongoDB for persistent task storage
- Organized structure using Express.js routing
